BIOCOLLOIDS LAB WEBSITE
=======================

Open index.html in a browser.

QUICK UPDATES
-------------
1. Research cards, press stories, events, publication links, and infrastructure:
   edit content.js
2. Group members and portraits:
   edit members.js
3. Replace images while keeping the same filename, or add a new image and update its path in content.js.

IMAGE FOLDERS
-------------
assets/images/          featured research and group images
assets/infrastructure/  equipment and scientific-method images
assets/people/          portraits

RECOMMENDED SIZES
-----------------
Featured research: 1600 × 1000 px, landscape
Infrastructure:    1600 × 900 px, landscape
Staff portraits:    800 × 1000 px, portrait
Group photo:        2000 × 900 px, wide landscape

UPCOMING EVENTS
---------------
Update EVENT_ITEMS in content.js. The current symposium date is 8 October 2026 at 13:00.

PUBLISHING
----------
This is a static HTML/CSS/JavaScript prototype. It can be opened locally, hosted on a static web server, or used as a visual/content template for the University CMS.
